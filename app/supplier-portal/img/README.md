# Login background image

Put a file called `login.jpg` in this folder and it appears as the left half
of the login and register pages.

If the file is missing the pages still work: the image reports a load error,
the controller hides it, and the form centres on the whole page instead.

## Licensing

Use an image you are allowed to use. Safe sources:

- https://unsplash.com  - free for commercial use, no attribution required
- https://www.pexels.com - same
- a photo you took yourself

Do **not** take images from travel sites, Google Images results or stock
libraries without a licence. This project is going to an employer.

Recommended: something around 1600x2000 or larger, portrait or square, since
it fills a tall half-screen panel.
